# Laya 语音 / 视频匹配 (Laya Voice & Video Match)

专为 iPhone / 移动端打造的 **Laya 语音与视频匹配通话界面生成器**（纯静态 Web 应用），延续 Laya 黑紫霓虹毛玻璃风格，支持手机浏览器全屏访问，可用于拍摄、录屏与素材制作。

## 在线访问
- **手机端直达链接**：https://sorenskr.github.io/laya-voice-match/

## 核心功能
- **双端自定义视频通话（延续 Laya 风格）**：
  - 支持「语音匹配模式」与「视频通话模式」无缝切换。
  - **对方视频**与**我的视频**完全独立上传自定义视频文件，也支持手机真实前后置摄像头。
  - 点击右上角悬浮小窗即可无闪烁对调主副视角（随时查看「对方全屏」或「对方看我时的全屏视角」）。
- **关闭摄像头白色虚化头像**：
  - 视频通话中点击「关摄像头」，我方画面即刻切换为**高透奶白柔焦虚化背景 + 我的清晰圆形头像**（支持在后台独立上传「我的头像」）。
- **前景文字 / UI 隐藏与 Laya Logo 独立控制**：
  - 点击顶部眼睛图标或后台开关，可一键隐藏全部前景文字与操作按钮，**默认唯独保留顶部 Laya Logo**（Laya Logo 本身也支持自由控制显示或隐藏）。
  - 隐藏后**双击屏幕任意空白处**即可立即恢复显示控制栏。
- **画面位置自由拖动与跨次自动保留**：
  - 视频通话中按住右上角悬浮小窗即可直接拖动摆放到屏幕任意角落（轻点则对调主副视角）。
  - 连续点击 **3 次左下角“我”** 即可进入/退出自由挪动模式（界面不显示多余移动图标），可手动拖动**Laya Logo、头像昵称、声波条、弹幕区、计时器、挂断按钮、底部栏、视频画面及关摄像头头像位置**；挪动后的位置、画面状态与上传的视频下次打开会自动保持，点击**“全部复位”**即可清除并恢复默认。
- **纯净无穿帮录屏体验**：
  - 界面绝不弹出“已载入视频”等系统提示气泡，无多余角标文字干扰，适合直接全屏录屏拍摄。
- **通话时间自定义与随机生成**：
  - 支持输入 `MM:SS` / `HH:MM:SS` / 秒数自定义时长，支持一键**定格时间**。
  - 支持设定分钟区间一键随机生成时长、快捷档位（刚接通 / 热聊 / 长聊）、打开自动随机以及随机挂断时刻。
- **原版功能完整保留**：
  - 动态梭形语音声波、对方头像/昵称/个人标签自定义、单人剧本自动回复、双机实时房间号同步、3 秒雷达匹配开场动画与底部距离微调。

## 本地运行与验证
双击项目目录下的 [启动服务.bat](file:///E:/code/laya-voice-match/启动服务.bat)（或运行静态服务 `npx serve -l 8088 .`），使用浏览器打开 `http://localhost:8088` 即可体验与预览。
