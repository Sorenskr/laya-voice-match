# Laya 语音匹配 (Laya Voice Match)

专为 iPhone / 移动端打造的 **Laya 语音匹配通话界面生成器**（纯静态单页 Web 应用），支持手机浏览器直接全屏访问，可用于拍摄、录屏与素材制作。

## 在线访问
- **手机端直达链接**：https://sorenskr.github.io/laya-voice-match/

## 核心功能
- **自定义头像与昵称**：在手机上直接点击圆形头像即可上传相册照片，点击昵称即可随时改名（自动本地保存）。
- **动态语音声波**：高对比度梭形语音声波跳动动画，静音或挂断后自动静止。
- **实时正计时与挂断状态**：支持从任意秒数开始正计时；点击挂断后自动定格并显示**通话时长**与**挂断时间**（支持自定义挂断时间）。
- **双模式布局切换**：内置「新版（单挂断键 + 添加好友/关注 + 底部发文字栏）」与「经典三键版（静音 + 挂断 + 免提）」一键切换。
- **iOS 全屏体验**：支持 iPhone Safari「添加到主屏幕」全屏运行，完美适配灵动岛与底部安全区。
